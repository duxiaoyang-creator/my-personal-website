# 个人主页项目

基于 Dimension 模板的现代化个人主页，使用纯 HTML、CSS 和 JavaScript 构建。

## 特点

- 🎨 现代化暗色主题设计
- 📱 响应式布局，适配所有设备
- 🌓 亮色/暗色主题切换
- 📊 动态技能展示
- 📁 项目展示区域
- 📄 模拟简历下载功能

## 使用方法

1. 克隆项目到本地
2. 用浏览器打开 `index.html` 查看效果
3. 修改内容：
   - 替换 `images/` 文件夹中的图片
   - 修改 `index.html` 中的个人信息
   - 调整 `style.css` 中的样式
   - 扩展 `script.js` 中的功能
