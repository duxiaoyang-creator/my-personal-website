# DXY · Anime Developer Portfolio

一个带有二次元视觉气质的个人主页，使用纯 HTML、CSS 与 JavaScript 构建。

- 响应式布局，适配桌面与移动端
- 深色 / 浅色主题切换
- 滚动入场动画与数字计数动效
- 连接 GitHub 项目与邮箱
- 使用 `images/avatar.jpg` 与 `images/background.jpg` 作为本地素材

## 本地预览

直接打开 `index.html`，或在当前目录运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。
